# 单一 Skill 安全与数据边界

## 保留在宿主的内容

- 地图、网页或 OTA 数据源凭证，以及 Ego Lite/Kimi WebBridge 的浏览器登录态；
- 用户身份、项目审批、项目保存和访问控制；
- 原始页面、原始地图响应和完整业务档案；
- 飞书/消息发送凭证和 Base 的访问控制。

测算核心只接收已规范化的确认点位、竞品事实和财务输入。页面采集器可在宿主进程中使用已授权的会话，但不得把密钥、Cookie、完整响应或其他项目数据写进其 JSON 回执、日志或引用文件。

如生成 HTML 竞品报告，渲染器只允许选定的 JPEG/PNG/WebP 图片以 `data_uri` 形式嵌入，并必须保留来源 URL。不要把整页 HTML、Cookie、截图中的敏感信息或受限资料写入其中；HTML 是可单独转发的交付物，应按原始图片的授权范围保管。

## Skill 内的最小保护

- 只接受确认的 GCJ-02 中心点；不接受模型自行生成的坐标。
- 只依据 2km Haversine 距离和最小来源记录形成正式竞品。
- 来源、物业定位、营业状态或报价不完整时返回证据不足。
- 核心测算不发送网络请求、不保存项目状态、不执行审批、不修改财务输入；页面采集器只向所选 Profile 的页面来源发起有回执的浏览器请求。
- 页面采集器只接受显式 `engine`/Profile；新 Mac Mini 的运行时预检、不可用引擎、验证码、登录失效或抓取失败必须返回错误/安装提示，禁止无记录地退回模型、其他来源或旧快照。
- Ego Lite 的认证会话只停留在运行它的 macOS 主机；Skill 回执只保存规范化页面证据和 URL，不包含 Cookie、令牌、完整请求/响应或浏览器存储。
- HTML 输出不加载外部脚本、样式或图片；远程来源仅作为用户点击时的追溯链接。
- `--format bitable` 仅输出无凭证的交付清单；Base 写入使用宿主已授权的用户或服务身份，并只上传清单内的内嵌图片字节，绝不从来源 URL 下载图片。

外部数据的商业使用和派生数据留存授权仍是宿主上线前置条件；它们不应被替换成开发任务授权或施工状态文件。
